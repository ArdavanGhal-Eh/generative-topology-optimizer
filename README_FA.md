## 📌 طرح مسئله و انگیزه صنعتی

در مهندسی هوافضا، خودروسازی و رباتیک پیشرفته:
1. **الزام به سبک‌سازی بدون افت سختی:** کاهش جرم قطعات (مانند براکت‌های اتصال تیتانیومی یا آلومینیومی) مستقیماً مصرف سوخت را کاهش داده و ظرفیت حمل بار را بالا می‌برد.
2. **رفع نقایص ناپایداری شطرنجی (Checkerboard Problem):** الگوریتم‌های بهینه‌سازی توپولوژی ساده‌لوحانه دچار توزیع چگالی متناوب شطرنجی و تکینگی وابسته به اندازه مش می‌شوند که در واقعیت فیزیکی ندارد.
3. **پل ارتباطی از ریاضیات تا ساخت (From SIMP to STL):** فیلد چگالی ریاضی $0 \le \rho_e \le 1$ به‌تنهایی قابل ساخت نیست؛ مهندسی ساخت نیازمند پایپ‌لاینی است که مرزهای متقارن را استخراج و آن را به یک فایل مش سه‌بعدی سالید و بسته (**Watertight STL**) برای نرم‌افزارهای اسلایسر پرینترهای سه‌بعدی و کم (CAM) تبدیل نماید.

این مجموعه با هسته سریع **C++20** و ماژول جانبی پایتون، این پل ارتباطی کامل را برقرار کرده است.

## ✨ ویژگی‌ها و نوآوری‌های فنی

- 🏗️ **روش جریمه متریال SIMP:** قانون توان جریمه $p=3.0$ برای راندن چگالی‌های میانی به سمت صفر (فضای خالی) یا یک (ماده صلب).
- 🧮 **حل‌کننده المان محدود تنش صفحه‌ای (Q4 Elements):** اسمبل سریع ماتریس سختی کل $\mathbf{K}$ و حل جابجایی‌ها با روش حل دستگاه تنک سیمپلیکال خولسکی یا گرادیان مزدوج در Eigen.
- 🎯 **به‌روزرسانی با معیارهای بهینگی (Optimality Criteria):** الگوریتم تنصیف سریع برای رعایت دقیق قید کسر حجمی مجاز ($V_f = 0.40$).
- 🛡️ **فیلتر حساسیت کانولوشنی:** حذف ناپایداری‌های شطرنجی با شعاع فیلتر $r_{\min}$.
- 🖨️ **ماژول تولید STL سه‌بعدی (`python_api/export_stl.py`):** استخراج کانتور دو بعدی با Marching Squares و اکسترود عمودی به مش سالید سه‌بعدی آماده پرینت.

## 📐 معادلات ریاضی SIMP و FEA

### تابع هدف و قیود بهینه‌سازی
کمینه‌سازی انرژی کرنش (نرمی سازه‌ای $c$):

$$
\min_{\boldsymbol{\rho}} \quad c(\boldsymbol{\rho}) = \mathbf{U}^T \mathbf{K}(\boldsymbol{\rho}) \mathbf{U} = \sum_{e=1}^{N_e} (\rho_e)^p \, \mathbf{u}_e^T \mathbf{k}_0 \mathbf{u}_e
$$

به‌طوری‌که:
$$\frac{1}{N_e} \sum_{e=1}^{N_e} \rho_e \le V^*, \quad \mathbf{K}(\boldsymbol{\rho}) \mathbf{U} = \mathbf{F}, \quad 0 < \rho_{\min} \le \rho_e \le 1$$

### قانون جریمه SIMP
مدول یانگ هر المان:
$$E_e(\rho_e) = E_{\min} + \rho_e^p (E_0 - E_{\min}), \quad p = 3.0$$

### فیلتر حساسیت چگالی
$$\frac{\widehat{\partial c}}{\partial \rho_e} = \frac{1}{\sum H_{ei}} \sum_{i} H_{ei} \frac{\partial c}{\partial \rho_i}, \quad H_{ei} = \max(0, r_{\min} - \text{dist}(e, i))$$

## 🚀 راهنمای نصب و اجرای سریع

```bash
# کلون مخزن
git clone https://github.com/ArdavanGhal-Eh/generative-topology-optimizer.git
cd generative-topology-optimizer

# پیکربندی و کامپایل
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# اجرای بهینه‌ساز C++
./build/topology_optimizer

# اجرای اسکریپت پایتون و تولید خروجی STL
cd python_api
pip install -r requirements.txt
python optimizer_runner.py --nelx 120 --nely 40 --volfrac 0.4
python export_stl.py --input topology_output.csv --thickness 15.0 --output bracket.stl
```
